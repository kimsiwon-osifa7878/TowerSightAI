# 현장 사진·영상 보관 폴더 (git 미추적)

실제 주차기 현장(구로 신안타워)에서 촬영한 카메라 사진과 영상을 **카메라별 폴더**에 그대로 넣습니다.
파일명에 접두사를 붙일 필요 없습니다. 폴더 이름이 곧 카메라 역할입니다.

| 폴더 | 카메라 | 보는 것 |
|---|---|---|
| `front/` | 카메라 2 (front) | 차량 정면 (번호판, 앞면 폭·좌우 치우침) |
| `rear_side/` | 카메라 3 (rear_side) | 차량 앞면 + 좌측면, 사선 |
| `opposite_side/` | 카메라 4 (opposite_side) | 차량 뒷면 + 우측면, 사선 |

- 사진(JPG/PNG)과 영상(MP4/MKV)을 같은 폴더에 섞어 넣어도 됩니다. 확장자로 구분합니다.
- 가장 유용한 자료: 빈 주차기(배경), 차량 정차 상태, 진입부터 정차까지 한 사이클 영상.
  같은 시각의 세 카메라 자료가 함께 있으면 교차 검증에 쓸 수 있으니 촬영 시각이 파일 정보에
  남아 있게 원본 그대로 옮겨 주세요.
- 카메라 3·4의 역할이 바뀌면 `.env`의 `VEHICLE_BOX_FRONT_LEFT_CAMERA` / `VEHICLE_BOX_REAR_RIGHT_CAMERA`만
  바꾸면 되고, 이 폴더 이름은 카메라 id 기준이라 그대로 둡니다.

이 폴더의 내용은 `.gitignore`로 제외되어 있으며(README만 추적), NAS `transfer/` 폴더를 거쳐 받은
파일을 그대로 옮겨 두면 됩니다. 차량 번호판이 보이는 자료는 외부 공유 금지.
